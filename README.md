# Luis Alvarez — Web Developer Portfolio

Personal portfolio showcasing selected projects and my approach to building, debugging, and improving web applications.

I'm a **self-taught full-stack web developer** currently focused on **Junior Frontend Developer opportunities**. My main frontend tools are React, JavaScript, HTML, and CSS, with practical backend experience using Node.js, Express, REST APIs, and PostgreSQL.

## About This Portfolio

This portfolio is intentionally built with **vanilla HTML, CSS, and JavaScript**.

The goal is to keep the interface simple, accessible, responsive, and focused on the work itself rather than on unnecessary visual effects or dependencies.

### Portfolio highlights

- Responsive single-page layout
- Fixed navigation with section links
- Accessible keyboard navigation and skip link
- Native HTML `<dialog>` for project details
- Focus restoration when project dialogs close
- Reduced-motion support
- Responsive project layouts for desktop, tablet, and mobile
- Minimal visual system based on typography, spacing, borders, and a small color palette
- No frontend frameworks or CSS libraries

## Run Locally

Clone the repository:

```bash
git clone https://github.com/lu-alvz-dev/web-portfolio.git
```

Move into the project:

```bash
cd web-portfolio
```

Because the portfolio has no build step or package dependencies, it can be served with any simple local development server.

For example, with Python:

```bash
python -m http.server 5500
```

Then open:

```text
http://localhost:5500
```

You can also use a development server such as VS Code Live Server.
